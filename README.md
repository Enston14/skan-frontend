 СКАН - Фронтенд

Проект для поиска публикаций о компании по ИНН.

 Используемые технологии:
- React 18 + TypeScript
- Vite
- React Router DOM
- Redux Toolkit

 Функционал:
- **Авторизация:** строгий вход по логину и паролю.
- **Главная страница:** описание сервиса, карусель преимуществ, тарифы.
- **Форма поиска:** поля ИНН, даты, чекбоксы, валидация.
- **Результаты поиска:** сводка, список документов, загрузка дополнительных публикаций.

 Примечание:
В проекте реализованы реальные API-запросы (в `src/api/`), но так как тестовый аккаунт API недоступен (возвращает ошибку 400), для демонстрации используются значения-заглушки (моки) внутри `src/store/slices/`.
